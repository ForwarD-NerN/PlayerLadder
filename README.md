# Player Ladder

Player Ladder introduces the ability to ride or pick up other players by simply right-clicking on them.

**This is an unofficial port of [Player Ladder](https://modrinth.com/mod/player-ladder) by ForwarD-NerN for Minecraft 26.1-26.4** (future versions planned if needed). This is a direct 1 to 1 port so there are no new features. If the original mod starts getting updated again I will archive this mod.

## Extra Features
- Extends the `/ride` command to support mounting entities on top of players.
- Includes [Pick Up Me](https://modrinth.com/mod/pickup-me) functionality (**Right Click Mode** needs to be switched to **PICK_UP** in the config).
- If installed on client, allows interacting with the world while there's an entity on top.
- Allows picking up/riding any living entity (off by default)

[FConfigLib](https://modrinth.com/mod/fconfiglib) is required.

The config can be edited via GUI if [Cloth Config API](https://modrinth.com/mod/cloth-config) and [Mod Menu](https://modrinth.com/mod/modmenu) are installed.
